# 🧋 Botea - Beverage Ordering Website

This project is a front-end web application designed for a beverage shop, allowing users to explore menus, view news, and place orders online.

## 🚀 Overview
Botea is a responsive website that simulates an online ordering system for drinks and food. It provides an intuitive user interface for browsing products and interacting with the system.

## 🛠 Technologies Used
- HTML5
- CSS3 (Bootstrap, custom styles)
- JavaScript (Vanilla JS, jQuery)

## 📂 Features
- 🧾 Interactive menu display
- 🛒 Order page interface
- 📰 News and updates section
- 🎨 Responsive and user-friendly design
- 📱 Mobile-friendly layout
